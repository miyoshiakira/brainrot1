Project: Brainrot Launch Simulator (2026 Edition)

1. コンセプト

「ポップでかわいいブレインロットキャラ」を収集・育成し、巨大な発射台（アイスクリームタワー型）を高くしていく放置系＋タイミングアクションゲーム。

2. 採用コアシステム

① クリティカル・ローンチ（Timing Mini-game）

単なるクリック放逐ではなく、発射時にスキル要素を介在させる。

仕様:

発射ボタンを押すと、パワーゲージが高速で往復する。

ゲージの中央（Perfect領域）で止めると、高度（Height）に x1.5〜x2.0 のボーナス。

高度が増すほど、ゲージの移動速度が上がり難易度が上昇する。

技術要件: RunService を使用したスムーズなUIゲージ更新と、クライアント側でのタイミング検知、サーバー側での正当性検証（不正対策）。

② サーバー・シンクロ・ボーナス（Global Event）

サーバー全体の「高さの合計」をトリガーにした協力型イベント。

仕様:

全プレイヤーの現在高度の合計が ServerThreshold（例：1,000,000m）に達すると発動。

発動時、サーバー全体に「Rainbow Rain」イベントが発生。

数分間、すべての発射で「レインボー・ブレインロット（超レア）」が確定または高確率で排出される。

技術要件: MessagingService またはサーバー内グローバル変数での高度同期。イベント開始のブロードキャスト通知。

3. 技術スタック（推奨）

Game Engine: Roblox Studio (Luau)

Data Persistence: DataStoreService (プレイヤーの高度、所持キャラ、資金)

UI Framework: Fusion または自作の動的UIコンポーネント

State Management: 各プレイヤーの Leaderstats とサーバー全体の GlobalStats

4. Claude Code へのプロンプト指示（例）

以下の手順で実装を依頼してください。

Prompt 1 (Base Setup):

「Robloxでブレインロット収集ゲームのベースを作成して。プレイヤーの高度(Height)と資金(Coins)を管理するLeaderstatsを実装し、一定時間ごとにキャラがCoinsを生成するシステムを作って。」

Prompt 2 (Critical Launch):

「仕様書①のクリティカル・ローンチ機能を実装して。ScreenGuiに往復するパワーゲージを表示し、タイミングよくボタンを押すと発射高度にボーナスが乗るロジックを組んで。UIはパステルカラーのポップなデザインにして。」

Prompt 3 (Global Event):

「仕様書②の共有発射台ボーナスを実装して。サーバー内の全プレイヤーのHeightを合計し、一定値を超えたら『Rainbow Rain』イベントを全クライアントに通知、エフェクトを発生させてレアキャラの排出率を上げて。」

5. ロジック上の工夫（エンジニア向けメモ）

高度の計算式:

$$Height = (BasePower + CharacterBonus) \times CriticalMultiplier$$

このように定義し、キャラクターの育成（パッシブ）と、プレイヤーの操作（アクティブ）を掛け算にすることで、やり込み要素を最大化します。

アンチチート: クリティカル判定をクライアントで行い、結果だけをRemoteEventで送るとチートの餌食になるため、ボタンを押した瞬間の「ゲージの位置（TimeまたはValue）」をサーバーに送り、サーバー側で倍率を確定させる設計にしてください。
