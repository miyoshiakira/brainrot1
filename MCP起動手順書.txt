=====================================
Roblox Studio MCP + Rojo 起動手順書
=====================================

【前提】
- MCPプラグインがインストール済み
  場所: %LOCALAPPDATA%\Roblox\Plugins\MCPPlugin.rbxmx
- Rojoがインストール済み
  場所: D:\Git\roblox_git\rojo.exe

=====================================
起動手順
=====================================

1. Rojoを起動
   - ターミナルでプロジェクトフォルダに移動
   - 以下のコマンドを実行:
     rojo serve
   - 「Rojo server listening」と表示されればOK

2. Roblox Studioを起動
   - プロジェクトを開く（新規 or 既存）

3. RojoプラグインでStudioと接続
   - Pluginsタブ → 「Rojo」をクリック
   - 「Connect」をクリック
   - 接続されるとsrcフォルダの変更がStudioに反映される

4. MCPプラグインを有効化
   - Pluginsタブ → 「MCP」アイコンをクリック
   - 「Connected」と表示されればOK

5. Claude Codeを起動
   - 通常通りClaude Codeを起動
   - MCPツールが自動的に利用可能になる

=====================================
役割の違い
=====================================

Rojo:  ファイル → Studio (一方向同期)
       スクリプトをVSCodeで編集、Git管理

MCP:   Claude ↔ Studio (双方向通信)
       3Dオブジェクト操作、プレイテスト実行

=====================================
接続確認
=====================================

■ Rojo
  srcフォルダのファイルを編集 → Studioに反映されるか確認

■ MCP
  Claude Codeで「Workspaceの中身を見せて」と依頼
  → オブジェクト一覧が返ってくれば接続成功

=====================================
トラブルシューティング
=====================================

■ MCP接続できない場合
  1. Roblox Studioを再起動
  2. Pluginsタブでプラグインが有効か確認
  3. Claude Codeを再起動

■ MCPプラグインが表示されない場合
  以下のコマンドで再インストール:
  npx robloxstudio-mcp@latest --install-plugin

■ Rojo接続できない場合
  1. rojo serveが起動しているか確認
  2. Studioのプラグインで再度Connect
